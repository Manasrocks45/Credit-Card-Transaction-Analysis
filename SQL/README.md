# SQL Analysis

This folder contains SQL scripts used for analysing the Credit Card Transaction dataset.

## Tools Used
- DuckDB
- SQL
- Google Colab

## SQL Files

| File | Description |
|---|---|
| `00_create_table.sql` | Creates the transactions table |
| `01_data_quality_checks.sql` | Checks data quality, missing values, and duplicates |
| `02_transaction_analysis.sql` | Performs transaction and fraud-related analysis |

## Analysis Areas
- Overall transaction KPIs
- Fraud vs. legitimate transactions
- Transaction categories and merchants
- Fraud rates by category and hour
- High-value transactions
- State-wise transaction analysis
- Age and gender analysis
- Distance analysis
- Daily and monthly trends
- Fraud rates by transaction amount band

## Dataset Note
The dataset is a simulated credit card transaction dataset. Fraud labels represent simulated classifications and should not be treated as real-world fraud predictions.
